<h1>Noor Boutique</h1>

<p>Fashion e-commerce website — women's eastern &amp; western wear with product catalog, filters, and shopping cart.</p>

<p>🔗 <b>Live:</b> <a href="https://noorboutique.vercel.app">https://noorboutique.vercel.app</a></p>

<h2>Features</h2>

<ul>
  <li>12 products with images</li>
  <li>Category filters, search &amp; sorting</li>
  <li>Shopping cart with slide-in drawer</li>
  <li>Fully responsive design</li>
</ul>

<h2>Tech Stack</h2>

<p>Next.js 14 · React · TypeScript · Tailwind CSS · Vercel</p>
